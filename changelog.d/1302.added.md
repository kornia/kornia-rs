`OrbDetector::build_pyramid_u8_into` and `OrbDetector::detect_and_extract_u8_from_pyramid` split ORB detection into building the u8 pyramid and detecting on it, so a tracker can run ORB on a pyramid it already holds. The caller's frame is level 0 without a copy and the level buffers are reused across frames. For the same image the features equal `detect_and_extract_u8` exactly.
