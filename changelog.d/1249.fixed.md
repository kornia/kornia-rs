`fast_detect_rows_u8` and `FastDetector::compute_corner_response_u8` with an arc length other than 9 no longer return FAST-9 scores from the AVX2/NEON path. That block implements FAST-9 only and now runs only for `arc_length == 9`. Scalar and SIMD scores are now bit-identical. The existing in-block candidate filter for images 800 px wide and up is unchanged, so on those images the row path can still return fewer corners than the scalar reference.
