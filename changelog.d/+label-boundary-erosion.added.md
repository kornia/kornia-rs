`kornia_imgproc::morphology::erode_label_boundaries`: shrink the regions of a `u8` / `u16` label map away from each other by writing a caller-chosen `fill` value into every pixel within `radius` of a differently labelled pixel (Manhattan distance with `Connectivity::Four`, Chebyshev with `Connectivity::Eight`; the image border is not a boundary). `radius = 1` marks the same pixels as `skimage.segmentation.find_boundaries(mode="thick")`. The CPU cost per pixel does not grow with the radius (separable capped distance transform on NEON, row bands on rayon), and device-resident images run on CUDA with the `cuda` feature (one launch for `radius <= 9`), identical to the CPU.
