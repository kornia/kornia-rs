`VideoReader` and `StreamCapture` can now report end-of-stream and pipeline errors instead of
leaving callers to invent timeouts. `try_grab_rgb8`/`try_grab_gray8` return `Grab::Eos` or an
error; the legacy `grab_rgb8`/`grab_gray8` still return `Ok(None)` when no frame is buffered.
File decoding now applies backpressure to the decoder, so a slow consumer no longer loses frames
silently, while live capture (`CameraCapture`) keeps dropping stale frames to stay current.
`get_fps` reports the negotiated frame rate as soon as negotiation completes (and `None` before
it) instead of the `1.0` default.
File decoding no longer waits for each frame's presentation time, so offline reads finish as fast
as the decoder allows (`VideoReader::set_realtime(true)` restores pacing).
