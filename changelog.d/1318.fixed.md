`VideoReader` and `StreamCapture` can now report end-of-stream and pipeline errors instead of
leaving callers to invent timeouts. `try_grab_rgb8`/`try_grab_gray8` return `Grab::Eos` or an
error; the legacy `grab_rgb8`/`grab_gray8` still return `Ok(None)` when no frame is buffered.
A full frame queue now applies backpressure to the decoder, so a slow consumer no longer loses
frames silently. File decoding no longer waits for each frame's presentation time, so offline
reads finish as fast as the decoder allows (`VideoReader::set_realtime(true)` restores pacing).
