kornia-imgproc's `cuda` feature now uses CUDA kernels written in Rust. The first,
`gray_from_rgb_u8`, is compiled to PTX by NVIDIA's cuda-oxide and replaces the NVRTC kernel
behind `cuda::color::gray::launch_gray_from_rgb_u8` (same signature, output byte-identical to
the CPU path). The PTX ships in a new crate, **`kornia-oxide-kernels`** (PTX + entry names, no
dependencies; its `ptx` feature, which kornia-imgproc's `cuda` turns on); building from
crates.io needs no extra toolchain. A kornia-rs checkout (or git dependency) builds the PTX
first with `cargo run -p kornia-oxide-kernels --example build_ptx`, which needs the cuda-oxide
toolchain (`scripts/cuda-oxide/install-toolchain.sh`).
GPU RGB8 -> Gray8 now needs an sm_75+ (Turing or newer) GPU; Maxwell/Pascal devices such as
Jetson Nano/TX2 lose it. CUDA color launchers now treat zero pixels as a no-op and reject pixel
counts whose element count passes `u32::MAX`. The `cuda-fusion`, `cuda-camera-sift` and
`cuda-camera-preprocess` examples now need `--features cuda`. The loader is
`kornia_tensor::cuda::oxide` (kornia-tensor's `cuda` feature now depends on
`kornia-oxide-kernels`). See `docs/cuda-oxide.md`.
