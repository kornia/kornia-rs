`SE3F64::adjoint`, `left_jacobian`, `right_jacobian`, `left_jacobian_inverse` and `right_jacobian_inverse` return `Mat6F64` instead of a row-major `[[f64; 6]; 6]`, with the same rows and columns: read `m[r][c]` as `m[(r, c)]`. `SE3F64` has not been released yet, so this only affects code built against `main`; `SE3F32` is unchanged.
