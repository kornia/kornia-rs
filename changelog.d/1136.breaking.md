`kornia_calib::ReconstructionConfig` gains a public `sprt: Option<kornia_3d::ransac::SPRTConfig>` field, forwarded to the per-view PnP-RANSAC registration; `None` keeps the previous behaviour. Also breaking for Rust code: `ReconstructionConfig` is an exhaustive, all-`pub` struct, so a downstream full struct literal now fails to compile with `missing field sprt` — add the field or construct via `..ReconstructionConfig::new(..)`. That makes this a minor-version API change (0.3.0).
