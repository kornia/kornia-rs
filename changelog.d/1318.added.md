New capture APIs report the end of a stream and pipeline errors without guessing. `try_grab_rgb8`
and `try_grab_gray8` (on `StreamCapture` and `VideoReader`) return
`Grab::Frame { image, pts }`, `Grab::Pending` or `Grab::Eos`, where `pts` is the frame's
presentation timestamp when the pipeline provides one. `is_eos` and `stream_error` expose the same
terminal state without grabbing a frame, and `VideoReader::set_realtime` switches file decoding
between offline (as fast as possible, the default) and paced playback.
