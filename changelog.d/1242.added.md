`kornia_3d::voxel`: voxel grids and voxel downsampling on the host.
`VoxelLayout` (voxel size and origin) maps points to `i32` voxel keys, negative keys included; `VoxelGrid<T>` is a sparse voxel map (`std::collections::HashMap`) with insert/get/remove/iteration and 6/18/26-neighbour iteration.
`VoxelView` groups a cloud by voxel without copying it (voxels in ascending key order, each voxel's point indices ascending; `VoxelView::new` or the reusable `VoxelDownsampler::view`), and reduces it to one point per voxel: `first()` and `nearest()` return a zero-copy `PointCloudView` of the input, `centroids()` an owned `PointCloud` with averaged colors and normals. `voxel_downsample(cloud, layout, mode)` is the one-call owned form, deterministic in ascending key order; `VoxelDownsampler::downsample_into` writes the points into caller-owned buffers.
`voxel_neighbour_counts` counts occupied neighbour voxels; `remove_sparse_voxels` filters on them and returns the kept points as a `PointCloudView`.
`kornia_3d::pointcloud::PointCloudView` is a borrowed index subset of a `PointCloud` (`PointCloud::select`, checked once; point/color/normal accessors and allocation-free iterators; `to_point_cloud()` for an owned copy).
