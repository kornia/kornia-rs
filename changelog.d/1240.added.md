`kornia_imgproc::filter::median_blur` accepts `u16` and `f32` images as well as `u8` (3×3 and 5×5, any channel count, replicate border), on CPU and, with the `cuda` feature, on device-resident images. The output is identical to `cv2.medianBlur` for `CV_16U`, and for `CV_32F` except in windows containing a NaN or both signed zeros (below). `f32` samples are ordered by IEEE 754 totalOrder (`f32::total_cmp`), so a NaN gives a deterministic result that is always one of the window's samples; OpenCV leaves NaN unspecified and does not order `-0.0` below `+0.0`, so windows with a NaN, or with both signed zeros, can differ from OpenCV (for zeros, only in the sign bit). The accepted pixel types are the sealed trait `kornia_imgproc::filter::MedianBlur`.
