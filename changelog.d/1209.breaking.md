Tukey robust kernel is now rejected instead of silently running as Cauchy: `bundle_adjust` returns `BaError::InvalidInput`, and `bundle_adjust_schur` returns `SchurBaError::Ba(BaError::InvalidInput(_))`. To keep the former finite-scale fallback, select `RobustKernelKind::Cauchy` explicitly. `PnPError` is now `#[non_exhaustive]` and gains `InvalidParams`, which `pnp::refine` returns for invalid robust-loss configuration (including Tukey) instead of `PnPError::SvdFailed`. Exhaustive `match` expressions on `PnPError` need a wildcard arm, and callers that handled `SvdFailed` for this case should handle `InvalidParams`.
