`kornia_3d::depth::CudaDepthProjector` (feature `cuda`) runs `unproject_depth` and `register_depth` on device-resident images: unprojection writes into a reusable `CudaPointCloud` in one ordered kernel (same points, same order and same pixel indices as the CPU), registration is an `atomicMax` z-buffer scatter with the same depth values as the CPU, bit for bit. Calls only enqueue work on the projector's stream.
