`kornia_3d::depth::CudaDepthProjector` (feature `cuda`) runs `DepthImage::to_pointcloud_into` and `DepthImage::register_into` on device-resident depth images (`CudaDepthProjector::to_pointcloud_into` / `register_into`, each `DepthImage` with its own `meter`): unprojection writes into a reusable `CudaPointCloud` in one ordered kernel (same points, same order and same pixel indices as the CPU), registration is an `atomicMax` z-buffer scatter with the same depth values as the CPU, bit for bit. Calls only enqueue work on the projector's stream.
