`Grab::Frame(image)` becomes `Grab::Frame { image, pts }`; migrate image-only patterns to `Grab::Frame { image, .. }`. Negotiated FPS is `None` before caps negotiation and after close instead of `Some(1.0)`. File readers decode without clock pacing by default; call `set_realtime(true)` for paced playback. Custom capture pipelines with unlimited `max-buffers=0` now have a five-sample bound and apply backpressure unless dropping is enabled. Custom pipelines that relied on the old drop-oldest ring should opt in to `drop=true` if their consumers cannot keep up. A sample missing its buffer or caps returns a per-grab error without setting a sticky stream error. RTSP/V4L2 capture retains only the newest queued frame. File-reader seeks now require `SeekFlags::FLUSH`; non-flushing seeks return an invalid-configuration error and leave buffered frames/EOS unchanged.
