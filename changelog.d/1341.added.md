Checked rotation matrix conversions in `kornia-algebra`: `Mat3F64::from_rows_array()` constructs a 3x3 matrix from a row-major flat buffer (transposing to glam's internal column-major layout); `Mat3F64::is_rotation()` validates orthonormality ($R^T R = I$) and proper handedness ($\det R = +1$) within a user-specified tolerance; `SO3F64::try_from_matrix()` validates the matrix and returns `Result<SO3F64, RotationError>`; and `RotationError` distinguishes non-orthonormal matrices (`NotOrthonormal { max_error }`) from reflections / improper matrices (`NotProper { det }`).
