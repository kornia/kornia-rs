Camera-model API changes in kornia-3d:

- `pose::triangulate_matched_points` and `TwoViewResult::median_parallax_deg` take **raw pixels** and unproject them through the camera, instead of undistorted points with the camera's distortion ignored. Callers passing normalized points with `PinholeCamera::IDENTITY` get identical results; callers passing already-undistorted points with a distorted camera must pass the raw pixels instead, or they undistort twice.
- `FisheyeCamera::project` and `unproject` move onto the `CameraModel` trait (import it). `project` returns the pixel only, not `(pixel, z)`, and `unproject` returns `Option<Vec3F64>`, `None` past the model's fold or when the inversion does not converge.
- `PinholeCamera::undistort` and `normalize` return `Option<Vec2F64>`, `None` for pixels with no valid undistorted preimage.
