`kornia_3d::depth::register_depth` reprojects a `u16` or `f32` depth image into a second pinhole camera given a `dst_from_src` `Pose3d`: nearest-pixel projection, a z-buffer so the nearer point wins, and an optional `splat_radius` that closes the holes of an upsampled destination grid. The output is `z_dst / metres_per_unit` (rounded for `u16`; for `f32` an identity registration returns `(d · metres_per_unit) / metres_per_unit`), checked against Open3D's `project_to_depth_image`. It accepts the same `metres_per_unit` values as `unproject_depth` and the same validity rule as `kornia_imgproc::depth`; the result is deterministic across threads and runs.
