`Grab::Frame(image)` becomes `Grab::Frame { image, pts }`; migrate image-only patterns to `Grab::Frame { image, .. }`. Negotiated FPS is `None` before caps negotiation instead of `Some(1.0)`. File readers decode without clock pacing by default; call `set_realtime(true)` for paced playback. Custom capture pipelines with unlimited `max-buffers=0` now have a five-sample bound and apply backpressure unless dropping is enabled. RTSP/V4L2 capture retains only the newest queued frame.
