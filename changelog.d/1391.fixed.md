Zero-element CUDA tensors (`zeros_cuda`, `uninit_cuda`, `Tensor::from_cudaslice`, and `Image::zeros_cuda` with a zero width or height) no longer build a `NonNull` from the null device pointer cudarc gives an empty slice. That was undefined behaviour. Debug builds aborted. In release, `zeros_cuda` returned `Err(NotCudaBacked)` for an empty shape, because `Result` uses the null value of that pointer to mark its `Err` case, and `Image::zeros_cuda` crashed with a segmentation fault.
