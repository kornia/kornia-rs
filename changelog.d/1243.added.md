With the `cuda` feature, `kornia_3d::voxel::CudaVoxelFilter` runs the voxel downsampling and the voxel neighbour count on device-resident points (stable radix sort by key, then segment reduce) with the same output, in the same order, as the CPU (`VoxelDownsampler::downsample_into` and the `VoxelView` reductions); device results stay device-resident in an owned `CudaVoxelCloud`. It needs compute capability 7.0 (sm_70) or newer; on older GPUs `CudaVoxelFilter::new` returns `VoxelError::UnsupportedComputeCapability`.
