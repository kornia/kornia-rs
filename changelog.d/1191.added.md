kornia-imgproc's `cuda` feature now routes bilinear and nearest-neighbor resize through
CUDA kernels written in Rust, following the pattern introduced for `gray_from_rgb_u8` in
#1185. The kernels are compiled to PTX by NVIDIA's cuda-oxide and live in
`kornia-oxide-kernels/device/src/resize.rs`; `launch_resize_bilinear_downscale_cuda` and
`launch_resize_nearest_downscale_cuda` try the oxide kernel first and fall back to the
existing NVRTC kernel (same signature, byte-identical output) on GPUs older than sm_75, in
builds without the PTX, or if the module fails to load. Bicubic resize stays NVRTC-only
until cuda-oxide supports lowering `f32::mul_add` to a native FMA instruction.
