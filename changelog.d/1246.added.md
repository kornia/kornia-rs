`kornia_3d::depth::DepthImage::register` / `register_into` reproject a `u16` or `f32` depth image into a second pinhole camera given a `dst_from_src` `Pose3d`: nearest-pixel projection, a z-buffer so the nearer point wins, and an optional `splat_radius` that closes the holes of an upsampled destination grid. Each image carries its own `meter`: the output is `z_dst / (1 / dst.meter())`, a correctly rounded division by the multiplier the unprojection uses (rounded for `u16`; for `f32` an identity registration between equal `meter`s returns `(d · s) / s`, `s = 1 / meter`), checked against Open3D's `project_to_depth_image`. It uses the same validity rule as `kornia_imgproc::depth`; the result is deterministic across threads and runs.
